Evidence Notes Page Learning Resource

This guide teaches users how the **Evidence Notes** page turns raw observations into auditable governance evidence.

Purpose

Evidence Notes capture narrative evidence, source context, confidence, role, cognition stage, and optional links to app entities.

Use the page to:

  • create evidence notes
  • attribute evidence to a user
  • classify evidence role
  • link evidence to scores, score components, recommendations, decisions, pilots, or KPIs
  • inspect existing evidence notes

Evidence is what prevents the app from becoming a score-only dashboard.

Evidence Roles

Use evidence roles carefully:

  • `mechanism`: explains how a condition or change works
  • `interpretation`: supports a reading of the data
  • `contradiction`: challenges or weakens a claim
  • `validation`: confirms, tests, or corroborates a claim

Contradiction should remain visible. Do not soften contradiction into ordinary weakness when it directly challenges a conclusion.

Optional Linkage

Evidence can be linked to:

  • score group
  • score component
  • recommendation
  • decision
  • pilot
  • KPI

Linking evidence makes downstream review stronger because later pages can show why a claim is supported, qualified, or contradicted.

Confidence And Source

Confidence records how strong the evidence is.

Source type records where it came from, such as interview, observation, document, metric, or governance review.

Low confidence evidence can still matter, especially when it identifies a risk or contradiction. It should just be interpreted carefully.

Downstream Impact

Evidence Notes feed:

  • Score Component Details
  • Alignment Dashboard
  • Recommendations
  • Pilot Tracker
  • KPI Dashboard
  • Lineage View
  • Governance Execution Review
  • Governance Summary
  • Comparative challenge review

Common Mistakes

Avoid writing vague evidence notes that do not say what claim they support or challenge.

Avoid leaving important evidence unlinked when a relevant entity exists.

Avoid treating a link as proof. The evidence narrative and confidence still matter.

Training Prompt

Ask the trainee to create one validation note and one contradiction note, link each to a relevant entity, and explain how each should change governance interpretation.

Completion standard: the user can use evidence to qualify a claim rather than merely decorate it.
