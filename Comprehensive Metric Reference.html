Comprehensive Metric Reference

Purpose

This reference explains how the metric set supports the developed product operating model:

  • Stage A: Understand reality. Diagnostic metrics describe current workplace structures, human experience, symbolic legitimacy, and alignment.
  • Stage B: Change reality intelligently. Execution signals from recommendations, pilots, KPIs, governance actions, and learning states test whether action is working.
  • Bridge: Connect diagnosis, action, evidence, and governance learning. Bridge metrics and review states help owners see whether insight became accountable action and whether conclusions remain supportable.

Use this document when you need deeper interpretation than the concise Metric Definitions.md glossary.

The Owner Value Of Metrics

The metric system is not a generic organizational health dashboard. It is designed to help owners govern workplace conditions with structural primacy and mission-flourishing integrity.

Metrics create value by helping owners answer six management questions:

  1. What is structurally happening?
  2. What are people experiencing?
  3. Where do symbolic claims diverge from structural conditions?
  4. Which recommendations should be preserved, reformed, replaced, watched, accepted, or deferred?
  5. Are interventions producing measurable improvement?
  6. What should governance approve, block, reopen, qualify, or escalate?

How To Read Score Movement

Stage A movement

Movement in Stage A scores means the diagnosed condition changed, or the evidence base changed. Ask:

  • Did the underlying workplace condition improve?
  • Did new evidence clarify a previous uncertainty?
  • Did a contradiction get resolved or newly discovered?
  • Are changes consistent across divisions or segments?

Stage B movement

Movement in Stage B signals means execution evidence has changed. Ask:

  • Did a pilot produce an outcome?
  • Did KPI progress improve or weaken?
  • Was the recommendation implemented or only accepted?
  • Did governance close an action without closing the learning question?

Bridge movement

Movement in Bridge metrics means interpretation or continuity has changed. Ask:

  • Did symbolic legitimacy improve without structural improvement?
  • Did structural action proceed without evidence?
  • Did a recommendation disappear across cycles?
  • Did scenario pressure make an otherwise sound action unsafe or incomplete?

Common Interpretation Risks

RiskWhy it mattersBetter reading
Treating Stage A diagnosis as actionA recommendation or score does not itself change conditions.Look for Stage B evidence: pilots, KPIs, governance actions, and learning state.
Treating accepted recommendations as improvementAcceptance is a decision, not proof of impact.Check execution feedback and downstream evidence.
Letting symbolic strength mask structural weaknessHigh trust or good language can coexist with harmful systems.Use the integrity gap and structural cap on overall scoring.
Treating all metrics as equalSome diagnose conditions, some test action, some protect interpretation.Use product-role classification before interpreting.
Hiding uncertainty with neutral scores50 can erase important evidence gaps.Label placeholders and create evidence follow-up.
Ignoring contradictionsContradictions often reveal blind spots.Treat them as review prompts, not nuisances.

Owner Summary

Stage A metrics help the owner understand current reality. Stage B signals help the owner test whether action works. Bridge metrics and governance states help the owner see whether the organization is learning responsibly rather than merely producing scores, recommendations, or reports.
