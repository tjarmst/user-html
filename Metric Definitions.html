Metric Definitions

Purpose

This document is a concise reference for the diagnostic metrics used by the Diagnostic Input page and the scorecard. It defines each metric and places it inside the product operating model:

  • Stage A diagnostic: helps the organization understand current reality.
  • Stage A / Stage B readiness: diagnoses whether the organization is ready to act and learn.
  • Stage B execution: tests whether action is producing movement.
  • Bridge / governance: connects diagnosis, action, evidence, and review.

Most rows below are Stage A diagnostic inputs. Stage B execution signals such as pilot outcomes, KPI progress, governance action status, recommendation lifecycle state, and learning state are produced on later workflow pages rather than entered as ordinary Diagnostic Input metrics.

Notes

  • All ordinary diagnostic metric observations use a 0-100 scale.
  • For positive metrics, higher values indicate healthier conditions.
  • For negative metrics, lower values indicate healthier conditions.
  • Diagnostic Input mainly supports Stage A. Pilot outcomes, KPI progress, recommendation lifecycle, governance action status, and learning state are Stage B or Bridge signals managed on later workflow pages.
  • For deeper interpretation, use Comprehensive Metric Reference.md.
