Home Page Learning Resource

This guide teaches users how the **Home** page works and how to use it as the safe starting point for a training or demo workspace.

Purpose

The Home page orients the user before they begin entering or reviewing governance data.

Use it to:

  • confirm the app is running against the intended local database
  • review the recommended startup sequence
  • initialize framework definitions when a real organization needs the metric and survey catalog
  • load sample data when a demo or training dataset is needed
  • understand the difference between framework definitions and the sample workspace before moving into Setup and Assessment Cycle

The page is not a governance review page. It is a launch point.

What The User Should Notice

The user should first inspect:

  • the current workspace context in the sidebar and context panel
  • the local database path shown in technical details
  • the recommended startup sequence
  • the explanation of the two data setup options

If the workspace context is empty, the next page should usually be **Setup**.

Data Setup Options

The Home page has two separate data setup actions.

Initialize Framework Definitions

Use this for a real organization workflow when Diagnostic Input or Survey Input needs the framework catalog.

This action creates or confirms:

  • metric definitions
  • survey questions

It does not create:

  • an organization
  • an assessment cycle
  • metric observations
  • survey responses
  • evidence notes
  • recommendations, decisions, pilots, KPIs, or governance records

It should not move the user out of their real organization context.

Load Sample Data

Use this for demos, training, and smoke-test walkthroughs.

The **Load sample data** button is available only before a user organization exists. Once the database contains any organization marked as user data, Home disables **Load sample data** and shows a message directing users to **Initialize framework definitions** for real organization workflows. This prevents a real workspace from being accidentally switched into the sample workflow.

This action creates or refreshes:

  • one sample organization: **Southern Horizon Health Services**
  • attribution users
  • active and prior assessment cycles
  • metric observations and survey responses
  • evidence notes and scorecards
  • recommendations, structural decisions, pilots, KPIs, and lineage links
  • governance review gates, action queue items, foresight mitigation, review history, and human validation challenges

The sample workspace is marked as sample data. Do not use it as real organizational evidence.

Safe Use

Before loading sample data:

  • confirm you are in the intended local workspace
  • confirm this is a demo or training run
  • confirm no user organization has already been created in this database
  • avoid mixing seeded examples with real organizational review unless the trainer clearly explains the difference

Sample data is useful because it gives users something to inspect, but it is not proof of real workplace conditions.

Downstream Impact

Home affects later pages by preparing the reference data they depend on:

  • Diagnostic Input and Survey Input can use framework metric and question definitions.
  • Setup can select the sample organization and users if sample data is loaded.
  • Assessment Cycle can select sample cycles if sample data is loaded.
  • Foresight Execution can use sample scenarios and watchpoints if sample data is loaded.

Once a user organization exists, Home should be used for framework definitions only. The sample workflow remains available in a fresh training database before real organization creation.

Training Prompt

Ask the trainee to explain the difference between:

  • the app being ready to use
  • framework definitions being available
  • sample data being available
  • a real organization/cycle being selected
  • real evidence being entered

Completion standard: the user can start from Home without mistaking framework definitions, sample examples, and real governance findings for one another.
